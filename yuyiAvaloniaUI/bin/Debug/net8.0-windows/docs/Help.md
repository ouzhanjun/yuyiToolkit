## 基础调整类

### 1. 灰度处理 (Grayscale)

**功能**: 将彩色图像转换为黑白灰度图像。

**原理**: 
- 使用亮度公式 `L = 0.299*R + 0.587*G + 0.114*B` 计算每个像素的亮度值
- 该公式考虑了人眼对不同颜色敏感度的差异（绿色最敏感，蓝色最不敏感）
- 将 RGB 三个通道都设置为计算出的亮度值

**参数**:
- `intensity`: 灰度强度 (0-100)，0 为原图，100 为完全灰度

---

### 2. 曝光调整 (Exposure)

**功能**: 调整图像的整体曝光程度。

**原理**:
- 基于线性曝光模型: `output = input * (2^exposure)`
- 曝光值以 EV (Exposure Value) 为单位
- 正值增加曝光（变亮），负值减少曝光（变暗）

**参数**:
- `intensity`: 曝光强度 (-100 到 100)

---

### 3. 对比度调整 (Contrast)

**功能**: 调整图像明暗之间的差异程度。

**原理**:
- 使用 S 型曲线对比度公式: `output = ((input / 255 - 0.5) * contrast + 0.5) * 255`
- 对比度因子通过 `1 + intensity / 100` 计算
- 扩展或压缩像素值的分布范围

**参数**:
- `intensity`: 对比度强度 (-100 到 100)

---

### 4. 饱和度调整 (Saturation)

**功能**: 调整颜色的鲜艳程度。

**原理**:
- 将像素从 RGB 空间转换到 HSL 空间
- 直接修改 S (Saturation) 分量
- 0 为完全去饱和（灰度），100 为最大饱和度

**参数**:
- `intensity`: 饱和度强度 (-100 到 100)

---

### 5. 亮度调整 (Brightness)

**功能**: 调整图像的整体明暗程度。

**原理**:
- 简单的线性偏移: `output = input + brightness`
- 对所有 RGB 通道添加相同的偏移值
- 正值变亮，负值变暗

**参数**:
- `intensity`: 亮度强度 (-100 到 100)

---

### 6. 色调调整 (Hue)

**功能**: 调整图像的整体色相。

**原理**:
- 将像素从 RGB 空间转换到 HSL 空间
- 旋转 H (Hue) 分量的值
- 色调值在色轮上从 0 到 360 度变化

**参数**:
- `intensity`: 色调偏移 (-180 到 180 度)

---

### 7. 温度调整 (Temperature)

**功能**: 调整图像的色温，使图像偏暖（橙色调）或偏冷（蓝色调）。

**原理**:
- 暖色调: 增加红色和绿色，减少蓝色
- 冷色调: 增加蓝色，减少红色和绿色
- 模拟一天中不同时刻光线的色温变化

**参数**:
- `intensity`: 温度强度 (-100 到 100)，正值偏暖，负值偏冷

---

### 8. 色彩平衡 (Color Balance)

**功能**: 分别调整图像中红色、绿色、蓝色通道的强度。

**原理**:
- 独立调整 R、G、B 三个通道
- 可以针对阴影、中间调、高光分别调整
- 用于校正色偏或创造特殊色调效果

**参数**:
- `intensity`: 调整强度
- `channel`: 要调整的通道 (红色、绿色、蓝色)

---

## 滤镜效果类

### 9. 模糊 (Blur)

**功能**: 对图像进行平滑模糊处理。

**原理**:
- 使用高斯模糊算法
- 卷积核: 二维高斯函数 `G(x,y) = exp(-(x²+y²)/(2σ²))`
- σ (sigma) 控制模糊程度，值越大越模糊
- 邻域内像素的加权平均

**参数**:
- `intensity`: 模糊半径 (与 sigma 相关)

---

### 10. 锐化 (Sharpen)

**功能**: 增强图像的边缘细节，使图像更清晰。

**原理**:
- 使用锐化卷积核:
  ```
  [ 0 -1  0]
  [-1  5 -1]
  [ 0 -1  0]
  ```
- 强调中心像素，从邻域中减去边缘信息
- 过度锐化会产生噪点

**参数**:
- `intensity`: 锐化强度

---

### 11. 去噪 (Denoise)

**功能**: 减少图像中的噪点，特别是在暗光环境下拍摄的图像。

**原理**:
- 使用非局部均值去噪算法 (Non-Local Means Denoising)
- 在整个图像中搜索相似像素块进行平均
- 保留边缘同时平滑纹理区域

**参数**:
- `intensity`: 去噪强度

---

### 12. 晕影 (Vignette)

**功能**: 创建设备镜头产生的暗角效果，突出图像中心。

**原理**:
- 计算每个像素到图像中心的距离
- 使用渐变函数降低边缘区域的亮度
- 渐变曲线: `1 - (distance / max_distance)^power`

**参数**:
- `intensity`: 晕影强度

---

### 13. 颗粒/噪点 (Grain)

**功能**: 添加胶片颗粒效果，增加图像质感。

**原理**:
- 生成随机噪点图案
- 混合到原图像上
- 可调整噪点的密度和大小

**参数**:
- `intensity`: 颗粒强度

---

## 艺术效果类

### 14. 棕褐色/复古 (Sepia)

**功能**: 创建复古棕褐色调效果，模仿老照片。

**原理**:
- 使用棕褐色转换矩阵:
  ```
  R' = 0.393*R + 0.769*G + 0.189*B
  G' = 0.349*R + 0.686*G + 0.168*B
  B' = 0.272*R + 0.534*G + 0.131*B
  ```
- 保留部分原始亮度信息

**参数**:
- `intensity`: 棕褐强度 (0-100)

---

### 15. 反相 (Invert)

**功能**: 将图像颜色反转，相当于胶片负片效果。

**原理**:
- 简单公式: `output = 255 - input`
- 白色变黑色，黑色变白色
- 彩色图像: 每个通道单独反转

**参数**:
- `intensity`: 反相强度 (0-100)

---

### 16. 色彩增强 (Vibrance)

**功能**: 智能增强图像的色彩饱和度，同时保护肤色。

**原理**:
- 类似于饱和度调整，但算法更智能
- 对已饱和的颜色减少增强力度
- 保护人脸肤色不被过度处理

**参数**:
- `intensity`: 色彩增强强度

---

### 17. 浮雕 (Emboss)

**立体浮雕效果，使图像呈现凹凸感。

**原理**:
- 使用浮雕卷积核，例如:
  ```
  [-2 -1  0]
  [-1  1  1]
  [ 0  1  2]
  ```
- 计算相邻像素的差异
- 添加光源方向效果

**参数**:
- `intensity`: 浮雕强度

---

### 18. 漫画效果 (Comic)

**功能**: 创建漫画/素描风格效果。

**原理**:
- 边缘检测提取轮廓线
- 减少色彩数量，创建色块效果
- 增加对比度和色彩饱和度
- 结合描边和平滑处理

**参数**:
- `intensity`: 漫画强度

---

### 19. 边缘检测 (Edge Detection)

**功能**: 突出显示图像中物体的边缘轮廓。

**原理**:
- 使用 Sobel 算子或 Laplacian 算子
- 计算像素梯度变化
- 梯度大的位置即为边缘

**算子示例 (Sobel)**:
```
[-1  0  1]    [-1 -2 -1]
[-2  0  2]    [ 0  0  0]
[-1  0  1]    [ 1  2  1]
```

**参数**:
- `intensity`: 边缘检测强度

---

### 20. 油画效果 (Oil Paint)

**功能**: 将图像转换为油画风格。

**原理**:
- 使用均值漂移 (Mean Shift) 或 K 均值聚类
- 将相似颜色的像素归为一类
- 创建笔触效果

**参数**:
- `intensity`: 油画强度/笔触大小

---

### 21. 水彩效果 (Watercolor)

**功能**: 创建水彩画风格效果。

**原理**:
- 边缘保持平滑
- 颜色扩散效果
- 添加水渍纹理

**参数**:
- `intensity`: 水彩强度

---

### 22. 素描效果 (Sketch)

**功能**: 将图像转换为黑白素描/手绘风格。

**原理**:
- 灰度转换
- 边缘检测提取轮廓
- 反转边缘颜色
- 添加纸张纹理

**参数**:
- `intensity`: 素描强度

---

### 23. 马赛克/像素化 (Mosaic/Pixelate)

**功能**: 将图像区域聚合为色块，隐藏细节。

**原理**:
- 将图像划分为小方块
- 每个方块内所有像素设为该区域的平均颜色
- 方块大小决定像素化程度

**参数**:
- `intensity`: 像素块大小

---

### 24. 鱼眼效果 (FishEye)

**功能**: 创建超广角鱼眼镜头效果。

**原理**:
- 极坐标转换
- 桶形畸变公式: `r' = r * (1 + k * r²)`
- k 为畸变系数
- 中心向外拉伸

**参数**:
- `intensity`: 畸变强度

---

## 液化变形类

### 25. 液化变形 (Liquify)

**功能**: 通过推动像素来变形图像，用于瘦脸、放大眼睛等美颜效果。

**原理**:
- 局部像素位移映射
- 为每个像素计算从源图像到目标图像的坐标变换
- 使用平滑的衰减函数控制变形范围

**变形类型**:

1. **收缩 (Pinch)**
   - 向中心点推挤像素
   - 产生向内的收缩效果
   - 用于瘦脸、瘦腰

2. **拉伸 (Stretch)**
   - 从中心点向外推挤像素
   - 产生向外的拉伸效果
   - 用于放大眼睛、拉长脸型

3. **左移 (Shift Left)**
   - 将区域内的像素向左移动

4. **右移 (Shift Right)**
   - 将区域内的像素向右移动

**参数**:
- `centerX`, `centerY`: 变形中心点坐标
- `radius`: 变形作用半径
- `intensity`: 变形强度
- `type`: 变形类型

**算法细节**:
```
对于每个在作用范围内的像素:
1. 计算到中心的距离 dist
2. 计算衰减因子 falloff = 1 - (dist / radius)
3. 使用平滑曲线: falloff = falloff² * (3 - 2*falloff)
4. 计算位移量 displacement = intensity * falloff * radius * 0.3
5. 根据变形类型计算新的采样坐标
6. 使用双线性插值获取新像素值
```

## 高级处理类

### 26. 景深效果 (Depth of Field)

**功能**: 模拟大光圈相机的浅景深效果，背景虚化。

**原理**:
- 计算每个像素到焦点的距离
- 距离越远，模糊程度越大
- 使用泊松盘采样或高斯模糊

**参数**:
- `intensity`: 虚化强度

---

### 27. 去雾 (Defog)

**功能**: 去除图像中的雾霾，提高清晰度。

**原理**:
- 基于暗通道先验 (Dark Channel Prior) 算法
- 估计场景透射率和大气光
- 恢复清晰图像

**参数**:
- `intensity`: 去雾强度

---

## 图像变换操作

### 28. 旋转 (Rotate)

**功能**: 按任意角度旋转图像。

**原理**:
- 使用仿射变换矩阵
- 坐标变换: 
  ```
  x' = x*cos(θ) - y*sin(θ)
  y' = x*sin(θ) + y*cos(θ)
  ```
- 使用反走样技术处理边缘

---

### 29. 裁剪 (Crop)

**功能**: 选取图像的矩形区域。

**原理**:
- 定义裁剪矩形
- 复制矩形内像素到新图像

---

### 30. 翻转 (Flip)

**功能**: 水平或垂直翻转图像。

**原理**:
- 水平翻转: x' = width - x - 1
- 垂直翻转: y' = height - y - 1
- 简单坐标映射，无像素损失

---

## 性能优化技巧

1. **并行处理**: 使用 `Parallel.For` 并行处理图像行
2. **内存管理**: 使用 `unsafe` 指针直接操作像素数据
3. **缓存机制**: 缓存常用计算结果（如 SKBitmap）
4. **渐进处理**: 大图像分块处理，避免内存溢出
