颜色主题样式指南

本文档展示 ColorTheme 生成的样式效果及其调用方式 - HTML预览版

1. 基础颜色 (Semantic Colors)

用于定义应用的核心语义色彩，支持主色、次色、成功、警告、错误、信息等状态色。

PrimaryColor
#1890FF
SecondaryColor
#722ED1
SuccessColor
#52C41A
WarningColor
#FAAD14
ErrorColor
#FF4D4F
InfoColor
#1890FF
// C# 调用示例 var theme = new ColorTheme(); theme.PrimaryColor = "#1890FF"; // 主色 theme.SecondaryColor = "#722ED1"; // 次要色 theme.SuccessColor = "#52C41A"; // 成功色 theme.WarningColor = "#FAAD14"; // 警告色 theme.ErrorColor = "#FF4D4F"; // 错误色 theme.InfoColor = "#1890FF"; // 信息色

2. 按钮样式 (FormElementStyle)

支持主按钮、次要按钮、虚线按钮等多种类型，包含默认、悬停、按下、禁用四种状态。

主按钮 (Primary Button)
次要按钮 (Secondary Button)
语义按钮 (Semantic Buttons)
// C# 调用示例 var formStyle = theme.FormElementStyle; // 主按钮样式 var primaryBg = formStyle.PrimaryBackgroundColor; // #1890FF var primaryHoverBg = formStyle.PrimaryHoverBackgroundColor; // #096DD9 var primaryActiveBg = formStyle.PrimaryActiveBackgroundColor; // #0050B3 // 次要按钮样式 var secondaryBg = formStyle.SecondaryBackgroundColor; // #FFFFFF var secondaryBorder = formStyle.SecondaryBorderColor; // #D9D9D9

3. 输入框样式 (Input Style)

包含文本输入框、下拉选择框、复选框、单选框、开关等表单元素。

文本输入框
下拉选择框
复选框 & 单选框 & 开关
// C# 调用示例 var formStyle = theme.FormElementStyle; // 输入框样式 var inputBg = formStyle.InputBackgroundColor; // #FFFFFF var inputBorder = formStyle.InputBorderColor; // #D9D9D9 var inputFocusBorder = formStyle.InputFocusBorderColor; // #1890FF var inputPlaceholder = formStyle.InputPlaceholderColor; // #BFBFBF // 复选框样式 var checkboxCheckedBg = formStyle.CheckboxCheckedBackgroundColor; // #1890FF // 开关样式 var switchOnBg = formStyle.SwitchOnBackgroundColor; // #1890FF var switchOffBg = formStyle.SwitchOffBackgroundColor; // #D9D9D9

8. CSS 导出

主题支持导出为 CSS 变量、SCSS 变量、JSON 格式。

// C# 导出示例 var theme = new ColorTheme(); // 导出 CSS 变量 string cssVariables = theme.ToCssVariables(); // 导出完整 CSS string fullCss = theme.ToFullCss(); // 导出按钮 CSS string buttonCss = theme.FormElementStyle.ToButtonCss(".btn-primary", ...); /* CSS 变量输出示例: :root { --primary-color: #1890FF; --primary-light: #40A9FF; --primary-dark: #096DD9; --success-color: #52C41A; --warning-color: #FAAD14; --error-color: #FF4D4F; --background-color: #FFFFFF; --foreground-color: rgba(0, 0, 0, 0.85); --border-color: #D9D9D9; } */

9. 自动同步机制

当修改基础颜色时，相关组件样式会自动更新。

// C# 示例 var theme = new ColorTheme(); // 修改主色时，按钮样式自动更新 theme.PrimaryColor = "#FF6600"; // 自动更新: // - FormElementStyle.PrimaryBackgroundColor = "#FF6600" // - FormElementStyle.PrimaryHoverBackgroundColor = 自动计算深色 // - FormElementStyle.PrimaryForegroundColor = 自动计算对比色 // 修改背景色时，面板样式自动更新 theme.BackgroundColor = "#1F1F1F"; // 自动更新: // - PagePanelStyle.PanelBackgroundColor = "#1F1F1F" // - PagePanelStyle.TabBackgroundColor = "#1F1F1F" // - 自动判断是否为深色主题 // 强制同步所有样式 theme.ForceSyncAllStyles(); // 关闭自动同步 theme.AutoSyncStyles = false;
